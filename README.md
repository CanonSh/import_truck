# IMPORT TRUCK L&B
# PROPUESTA DE DISEÑO
Prototipo de sitio web y maquetación frontend para **Import Truck L&B**, enfocado en la exhibición de inventario de camiones, vehículos livianos, servicios de alquiler de transporte y bolsa de trabajo para conductores.

---

# Instrucciones:

1. Clona el repositorio del proyecto
2. Accede a la carpeta del proyecto
3. Instala dependencias
4. Corre el proyecto

```bash
cd import_truck
npm install
npm run dev
```
5. Abre tu navegador en http://localhost:5173 para visualizarlo
