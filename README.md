# IMPORT TRUCK L&B
# PROPUESTA DE DISEÑO
Prototipo de sitio web y maquetación frontend para **Import Truck L&B**, enfocado en la exhibición de inventario de camiones, vehículos livianos, servicios de alquiler de transporte y bolsa de trabajo para conductores.

---

# Acceder al proyecto, Instalar dependencias y correr el proyecto:

...bash
cd import_truck
npm install
npm run dev
...
Abre tu navegador en http://localhost:5173
